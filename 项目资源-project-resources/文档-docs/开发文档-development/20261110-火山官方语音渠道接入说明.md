# 20261110-火山官方语音渠道接入说明

## 目标与范围

在 VoiceKey 现有渠道旁，额外增加“豆包语音（火山官方）”。保留原有豆包输入法渠道、此前的延迟优化、其他渠道、右 Option 长按快捷键和边说边上屏体验。

新增渠道使用用户自己的火山引擎凭据直接调用官方豆包语音服务，不借用输入法客户端的设备身份。官方语音 API 与输入法专用服务的参数和效果可能不同，不能承诺输出及速度完全一致。

## 接口与计费

- 模型：豆包流式语音识别 2.0，小时时长版。
- 服务资源：`volc.seedasr.sauc.duration`。
- 接口：`wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_async`。
- 鉴权：新版控制台 API Key，HTTP 请求头 `X-Api-Key`。
- 音频：16 kHz、单声道、16 bit PCM。每包约 200 ms；积压时包间隔不小于 100 ms，避免瞬时灌入。
- 返回：持续显示中间文字，结束后修正为定稿；启用标点、数字规范化与二遍识别，关闭语义删改。
- 2026-11-10 查阅官方公开按调用后付费单价为 **1 元/小时**；实际抵扣、优惠和账单以火山账户为准，未替用户购买资源包或充值。

## 使用方法

1. 火山控制台中确认已开通“流式语音识别 2.0”，创建独立 API Key。
2. 在 VoiceKey“识别”页选择“豆包语音（火山官方）”。
3. 将 API Key 粘贴到下方“火山官方语音配置”，点击“保存密钥”。保存不会发起识别。
4. 在目标文本框按住右 Option 说话，松开结束；沿用原有实时上屏设置。

“已保存密钥”表示凭据已存入本机，不代表服务端已验证。实际使用时若开通、额度或权限有问题，会返回识别错误。

## 凭据与费用边界

- API Key 仅保存在 macOS 钥匙串，服务名 `do.j3.voicekey.volc-speech`、账户名 `api-key`；不写入普通设置、Git、修复记录或日志。
- 前端只接收“是否已配置”等状态；已保存的密钥不会读回输入框，保存后输入框会清空。
- “移除密钥”只删除本机保存；需要云端撤销时，到火山控制台禁用或删除对应 API Key。
- 非 macOS 平台暂不显示此扩展渠道，未提供明文存储降级路径。
- 新渠道不自动加入默认多渠道列表。配置异常后的默认列表恢复也排除此渠道。
- 渠道对比仅在用户于多渠道中明确勾选“火山官方”后，才将其加入对比。
- 按键按下时不为官方付费渠道预建会话，避免单纯按修饰键就打开服务连接。
- 保存、替换、移除密钥只操作本地钥匙串；没有自动发起付费“验证”请求。


此命令会真实上传给火山并产生识别用量，需明确授权后运行。输出仅包含成功与否、识别文字与时间，不输出 API Key。测速采用每 20 ms 的绝对采集时刻，避免测试程序累计睡眠误差。
